# نظام أرشفة الكتب الرسمية

برنامج ديسك توب احترافي لأرشفة الكتب الرسمية، مبني بلغة Python وواجهة PyQt5، يعمل بالكامل دون إنترنت وقاعدة بيانات SQLite محلية.

## المميزات
- إضافة كتاب جديد بالحقول: رقم الكتاب، نوع الجهة المرسلة (وزارة/هيئة/مديرية/قسم/شعبة/وحدة)، اسم الجهة، تاريخ الكتاب، عنوان/موضوع الكتاب، الملاحظات.
- **استخراج تلقائي بالذكاء الاصطناعي**: ارفع صورة أو ملف PDF للكتاب الأصلي، ويقوم Claude API بقراءته وتعبئة كل الحقول تلقائيًا لمراجعتها.
- شاشة **مراجعة وتأكيد** تظهر قبل الحفظ النهائي حتى تدقق البيانات بنفسك.
- أرشيف كامل مع بحث بأي تفصيلة (كلمة عامة، نوع الجهة، رقم الكتاب، نطاق تاريخ).
- تعديل وحذف أي كتاب مؤرشف.
- نسخ احتياطي للأرشيف بالكامل إلى ملف تختاره، واستعادته وقت ما تحتاج.

## تفعيل الاستخراج التلقائي بالذكاء الاصطناعي
1. احصل على مفتاح API من https://console.anthropic.com (Account Settings > API Keys).
2. افتح البرنامج → صفحة **الإعدادات** → الصق المفتاح → احفظ.
3. من صفحة "إضافة كتاب جديد" اضغط **"اختيار ملف واستخراج البيانات"** واختر صورة أو PDF للكتاب.
4. راجع الحقول اللي اتعبت تلقائيًا وعدّل أي خطأ، ثم اضغط "مراجعة وحفظ" كالمعتاد.

⚠️ **خصوصية**: هذه الميزة فقط تحتاج إنترنت، وترسل محتوى الملف إلى خوادم Anthropic لتحليله. باقي البرنامج (الحفظ، البحث، النسخ الاحتياطي) يعمل بالكامل بدون إنترنت. لا تستخدم الاستخراج التلقائي مع كتب سرّية للغاية إلا وفق سياسة جهتك. المفتاح يُحفظ في `config.json` بجانب البرنامج كنص عادي غير مشفّر.

## طريقة التشغيل

### 1) تثبيت المتطلبات (مرة واحدة فقط)
افتح Command Prompt / Terminal داخل مجلد البرنامج ونفّذ:

```
pip install -r requirements.txt
```

يتطلب وجود Python 3.8 أو أحدث مثبت على الجهاز (Windows/Linux/Mac).

### 2) تشغيل البرنامج
```
python main.py
```

هيفتح البرنامج مباشرة بالواجهة، وقاعدة البيانات (`archive.db`) هتتكون تلقائيًا بجانب ملفات البرنامج أول ما تفتحه.

## بناء برنامج تثبيت حقيقي لويندوز (Installer)

بما إني بشتغل حاليًا على بيئة Linux، مش بقدر أنتج ملف `.exe` أو برنامج تثبيت لويندوز مباشرة من هنا. الحل المُجهّز في المشروع (`.github/workflows/build-windows.yml` + `installer.iss`) بيخليك تحصل عليه تلقائيًا مجانًا عبر خوادم GitHub الحقيقية اللي بتشغل ويندوز فعليًا. اتبع الخطوات:

### الطريقة الموصى بها (تلقائية عبر GitHub - مجانية)
1. اعمل حساب مجاني على https://github.com (لو مفيش عندك).
2. اعمل **New repository** جديد (خاص أو عام، زي ما تحب) وسمّيه مثلاً `archive-app`.
3. من زر **Add file → Upload files**، اسحب كل ملفات المجلد ده بالكامل (بما فيها مجلد `.github` بمحتوياته) وارفعها، ثم اضغط **Commit changes**.
4. روح لتبويب **Actions** فوق الصفحة. لو ظهرت رسالة تفعيل، اضغط **I understand my workflows, go ahead and enable them**.
5. اختار **"بناء برنامج التثبيت لويندوز"** من القائمة الجانبية، ثم اضغط **Run workflow** (زرار أخضر) ثم **Run workflow** تاني للتأكيد.
6. استنى حوالي 3-5 دقائق لحد ما تلاقي علامة ✅ خضرا جنب التشغيل.
7. افتح التشغيل، وهتلاقي تحت **Artifacts** ملفين للتنزيل:
   - **برنامج-التثبيت-الكامل**: ملف `تثبيت_الارشيف_الرسمي.exe` — ده اللي تشغله على أي جهاز ويندوز عشان ينصب البرنامج فعليًا (باختصار في قائمة ابدأ وسطح المكتب + إلغاء تثبيت).
   - **الأرشيف_الرسمي-exe-مباشر**: نسخة exe مباشرة بدون تثبيت، لو حابب تشغله بدون تنصيب.

### الطريقة البديلة (لو عندك جهاز ويندوز وعايز تبنيه بنفسك محليًا)
```
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --onefile --windowed --name "الأرشيف_الرسمي" main.py
```
بعدها نزّل ونصّب برنامج **Inno Setup** (مجاني) من https://jrsoftware.org/isdl.php، افتح ملف `installer.iss` بيه، واضغط **Build → Compile**. هتلاقي المثبت جاهز في مجلد `installer_output`.

## هل البرنامج جاهز بالكامل؟

**جاهز ومُختبر فعليًا (تم تشغيله والتأكد منه):**
- إضافة / تعديل / حذف الكتب بكل الحقول المطلوبة
- المراجعة والتأكيد قبل الحفظ النهائي
- البحث الشامل بكل التفاصيل (كلمة عامة، نوع الجهة، رقم الكتاب، نطاق تاريخ)
- النسخ الاحتياطي والاستعادة الكاملة للأرشيف
- الاستخراج التلقائي للبيانات من صورة/PDF عبر الذكاء الاصطناعي
- تصميم عربي احترافي (RTL) متسق على كل الصفحات

**غير موجود حاليًا (يحتاج طلب صريح لو عايزه):**
- تصدير نتائج البحث أو الأرشيف كامل إلى Excel
- طباعة تقرير أو إيصال بالكتاب
- إرفاق وحفظ صورة/PDF الكتاب الأصلي مع السجل داخل الأرشيف نفسه (حاليًا الاستخراج بيقرا الملف ويملي الحقول بس، ومايحفظش الملف الأصلي)
- نظام صلاحيات لأكتر من مستخدم (اسم مستخدم/كلمة مرور)
- تنبيهات أو تذكيرات (مثلاً كتاب يحتاج متابعة خلال مدة معينة)
- مزامنة سحابية بين أكتر من جهاز

قولي لو عايز أي حاجة من دول أضيفها.


## ملاحظات مهمة
- خد نسخة احتياطية بشكل دوري من صفحة "النسخ الاحتياطي" حفاظًا على بياناتك.
- ملف قاعدة البيانات `archive.db` هو كل بياناتك — احتفظ بنسخة منه في مكان آمن (فلاشة / كلاود) بجانب النسخ الاحتياطي من داخل البرنامج.
